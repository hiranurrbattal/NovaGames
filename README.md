# NovaGames 🎮

NovaGames is a Steam-inspired console game platform developed with C# using Object-Oriented Programming principles.

## Features
- User Authentication
- Admin Panel
- Game Store
- Free & Paid Games
- Rating System
- Achievement System
- Balance System
- JSON Data Storage
- Exception Handling
